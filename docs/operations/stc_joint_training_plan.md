# STC 联合训练实施计划与验收合同

更新：2026-10-22。任务来源：[原任务书及确定性补充](stc_joint_training_task.md)。

## 确定性合同（覆盖任务书中未明确或不同的表述）

- 唯一状态表示 `z128`；`t32`；原始有效 AlphaEarth64 与表格编码32直接拼接为 `b96`，不整体 L2 归一化；预测输入256；独立 VIIRS 256→128→6、POI 256→128→12。
- AlphaEarth 缺失使用可学习64维 token；availability 作为表格背景编码器额外的二值输入，不额外增加输出维度。有效 AlphaEarth 的64个值保持不变。
- Anchor 按任务分别对有限标签、正且有限设计权重归一化。有两个有效任务时各0.5，仅一个有效任务时其系数为1；没有监督的 batch 不调用 optimizer.step（包括避免 AdamW weight decay 改动）。
- Alignment 独立按族计算，不把18维标签混为一个相关性；仅在存在可靠共同支持及有效正样本对时激活。只对有效对齐任务取平均，零有效任务时为可微零。
- 缺失/NaN 标签和非正/非有限权重显式屏蔽；有效位置非有限模型输出报错；零分母不参与平均。SE 只进入对齐的现有可靠性修正，主 Anchor 保持 design-only。
- `viirs_only`、`poi_only`、`joint` 使用同一18维联合数据包、相同城市划分/训练集标准化/影像与字段 schema、相同128/32/96维架构及两个头；训练任务 mask 决定参与监督的任务。按任务在相同测试事件与有效标签上比较，历史模型不覆盖。
- 添加可配置全局梯度裁剪（默认1.0；可关闭）。记录裁剪前联合梯度范数、裁剪后范数和裁剪比例。
- 任务梯度诊断针对共享 State Encoder，以各任务对实际总损失的贡献（包含Anchor与Alignment各自有效任务平均系数）计算梯度范数与余弦/冲突；两任务贡献之和等于总损失。使用autograd.grad，不写入.grad，不额外optimizer.step；记录诊断频率及有效系数。
- 记录 AlphaEarth64/表格32 的 RMS 与输入梯度范数，缺失 token 与表格编码器的参数梯度范数。原始 AlphaEarth 不训练一个额外的64维映射。
- 保留旧版 STC 检查点加载；新 checkpoint 记录 architecture_version、training_mode、分支维度、输出布局、标准化、输入哈希和影像契约。新模式固定 z128，拒绝不一致参数。

## 实施顺序与文件清单

1. `encoder.py`、`model.py`：增加直接背景编码与共享双头模型，保留历史模型加载。
2. `loss.py`：增加按任务损失和独立有效性统计；补齐有限性处理。
3. `training/joint.py`：统一三模式训练、任务梯度诊断、裁剪、验证选模、日志和检查点；规范与模块化入口均转入该唯一实现。
4. `cli.py`、`trainer.py`、`training/runner.py`：增加模式和诊断参数；旧模式兼容。修复旧 STC 默认基线的属性访问。
5. `dataset.py`、`pretraining_dataset.py`：复核事件对齐、18维顺序、并集可用性和按族 masks；补充联合数据合同与检查。
6. `evaluation.py`、`baselines.py`、评估入口：统一传递 response_offsets；增加每族均值预测对照及固定评估支持指纹。
7. `export.py`：恢复新模型，导出共享 emb_0..127、两个预测头及身份/任务 masks；导出元数据。
8. 对照配置及运行器：三主组、Anchor-only、TC-only、z-only、模态消融；预检共同数据版本和划分，保存每族结果及支持一致性审计。
9. 添加功能/边界/梯度/检查点/CLI测试；运行相关回归、完整Python测试和本地小规模训练。

## 验收标准

- 张量：z[B,128]、t[B,32]、b[B,96]、x[B,256]、两头[B,6]/[B,12]；固定S改变T/C不改变z；全模态和逐模态缺失均保持合法形状。
- 数值：双任务/单任务/全缺失；每族独立零样本对；NaN标签与SE；零/无穷权重；无除零，无意外非有限梯度；active任务严格等权。
- 梯度：两族单独能更新同一State Encoder；inactive头无更新；诊断开启/关闭的更新一致；裁剪阈值生效；联合与分任务梯度日志可审计；冲突样例可识别。
- 训练：三主组同源schema与split；训练有有效步；验证决定best checkpoint；测试仅最终评估；恢复/导出预测数值一致。
- 评估：按族的预测误差、训练均值基线提升、检索/近邻相关、未见城市指标；测试支持ID/cell掩码指纹一致；固定池置换observed与检索统计量一致。
- 产物：任务要求的六个训练文件、共享128维导出、两头预测、实验状态与支持审计；严格区分fixture smoke与真实正式性能证据。
- 本地若无完整正式联合发布包，使用显式non-production合成影像/标签完成工程闭环；真实数据科学比较记录pending并提供可执行命令，不能以fixture分数代替。
