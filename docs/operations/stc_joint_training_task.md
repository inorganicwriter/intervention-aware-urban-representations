# STC 联合训练架构改造任务书

## 1. 改造目标

将当前 STC（State–Intervention–Context）表示学习模型升级为共享状态表征的联合多任务模型。

核心目标：利用地铁开通前的多模态城市状态，学习一个128维、对政策响应敏感的空间 embedding，并通过 VIIRS 与 POI 两类准实验因果响应共同监督该表征，实现响应预测、响应模式检索和跨城市迁移。

采用以下固定架构：

- 一个共享 State Encoder，输出 `z`；
- 一个 Intervention Encoder，输出 `t`；
- 一个 Context Encoder，输出 `b`；
- 一个 VIIRS 响应预测头，输出6维；
- 一个 POI 响应预测头，输出12维；
- 两类任务共同训练同一个 State Encoder。

请先检查实际代码，确定各模块、数据接口和损失函数的位置，再按以下规范实施修改。

## 2. 最终架构与维度

### 2.1 状态分支 S：输出128维 z

输入包括：

- 15个开通前 POI/VIIRS 历史数值及对应 availability masks；
- 全部合法的开通前街景图像；
- 开通前六年的卫星影像序列及缺失 masks。

三个模态分别编码：

| 模态 | 编码方法 | 输出维度 |
|---|---|---:|
| POI/VIIRS 历史 | MLP | 128 |
| 街景 | 冻结 DINOv2 + 可训练投影 + 时间感知注意力聚合 | 128 |
| 卫星序列 | 逐年 CNN + 年份 embedding + Masked GRU | 128 |

融合过程：

`128 + 128 + 128 = 384`

`384 → 融合 MLP → 128`

最终：

`z: [B, 128]`

对 z 执行 L2 归一化。

三个分支的128维向量是供融合网络使用的中间特征。最终 z 是统一学习的状态表征，其坐标共同编码多个模态的信息。

时间屏障：

- 街景图片拍摄月份必须早于对应事件的开通月份；
- 卫星影像年份必须早于开通年份；
- POI/VIIRS 历史仅使用规定的开通前 lag1–3 数据。

保留现有图像预处理、时间编码和缺失处理机制，并确保所有输入严格遵守开通前信息边界。

### 2.2 干预分支 T：输出32维 t

输入为现有7个干预属性及其 masks：

- opening_year；
- is_transfer_at_opening；
- is_new_line_opening；
- is_extension_opening；
- is_terminal_at_opening；
- n_lines_at_opening；
- same_month_openings。

编码过程：

`7个值 + 7个 masks → Intervention Encoder → 32维`

最终：

`t: [B, 32]`

### 2.3 背景分支 C：输出96维 b

背景由两部分组成：

| 子分支 | 输入 | 输出 |
|---|---|---:|
| AlphaEarth | 64维预训练卫星嵌入 A00–A63 | 64 |
| 表格背景 | 当前保留的12个背景字段及对应 masks | 32 |

融合过程：

`AlphaEarth64 + ContextTabular32 = b96`

最终：

`b: [B, 96]`

表格背景沿用当前数据 schema 中保留的12个字段，房价相关字段及其派生特征从背景输入中移除。

AlphaEarth 保留64维特征。表格背景通过独立的可训练编码器映射为32维。

b 只作为响应预测的条件输入。

### 2.4 预测器输入：256维

将三个向量拼接：

`x = concat(z, t, b)`

维度：

`128 + 32 + 96 = 256`

因此：

`x: [B, 256]`

最终用于检索、聚类、UMAP 和空间表征分析的 embedding 为 z。拼接后的 x 用于条件化响应预测。

## 3. 联合模型结构

模型一次前向计算完成两个响应任务：

```python
z = state_encoder(S)           # [B, 128]
t = intervention_encoder(T)    # [B, 32]
b = context_encoder(C)         # [B, 96]

x = concat(z, t, b)            # [B, 256]

tau_hat_viirs = viirs_head(x)  # [B, 6]
tau_hat_poi = poi_head(x)      # [B, 12]
```

两个预测头采用独立参数：

| 预测头 | 网络结构 | 输出含义 |
|---|---|---|
| VIIRS | 256 → 128 → 6 | 六个开通后时间点的灯光因果响应 |
| POI | 256 → 128 → 12 | 四类 POI 指标在开通后三个年度的因果响应 |

沿用现有预测器的激活函数、Dropout 和初始化方案。

共享的 State Encoder、Intervention Encoder 和 Context Encoder 在同一次联合训练中共同服务于两个预测头。

## 4. 联合数据集

以处理网格—地铁开通事件作为基本样本单位。

每个样本包含：

- 城市和事件标识；
- 状态输入 S；
- 干预输入 T；
- 背景输入 C；
- VIIRS 响应标签、mask、标准误和设计权重；
- POI 响应标签、mask、标准误和设计权重；
- split、quality_grade 和 final_training_mask。

VIIRS 与 POI 保留各自的标签可用性。每项任务根据自己的有效标签计算损失，使具有部分有效标签的样本能够参与相应任务训练。

沿用现有正式监督边界：

- VIIRS：6个响应时间点；
- POI：4类指标 × 3年；
- 因果估计方法：同城 Matching + GSC。

正式训练显式指定：

`--families viirs,poi --methods matched,gsc`

请检查数据集构建、batch collate、mask、标准化和权重计算，确保两类任务的样本索引正确对齐。

## 5. 联合损失函数

### 5.1 响应预测损失

分别计算 VIIRS 和 POI 的设计加权 Huber 损失。

VIIRS：

\[
L_V =
\frac{
\sum_{i,k}m^V_{ik}w^V_{ik}
\operatorname{Huber}
(\hat\tau^V_{ik}-\tau^V_{ik})
}{
\sum_{i,k}m^V_{ik}w^V_{ik}
}
\]

POI：

\[
L_P =
\frac{
\sum_{i,k}m^P_{ik}w^P_{ik}
\operatorname{Huber}
(\hat\tau^P_{ik}-\tau^P_{ik})
}{
\sum_{i,k}m^P_{ik}w^P_{ik}
}
\]

两项损失分别根据各自有效标签及权重进行归一化，再组合为：

\[
L_{\mathrm{anchor}}
=\frac12L_V+\frac12L_P
\]

先采用等权联合训练基线，并记录两项损失的尺度与共享编码器的梯度范数。

### 5.2 响应相似性对齐损失

分别构造两类任务的响应相似性对齐损失：

- `L_align_viirs`：根据 VIIRS 响应轨迹计算；
- `L_align_poi`：根据 POI 响应轨迹计算。

两项损失都直接作用于同一个 z。

沿用现有 Soft-InfoNCE 的基本机制：

1. 根据有效响应标签构造网格之间的软相似性目标；
2. 使用共同有效的响应维度计算相似性；
3. 结合现有设计可靠性及标准误相关处理；
4. 根据 z 的相似度构造预测邻居分布；
5. 对有效样本对计算对齐损失。

联合对齐损失：

\[
L_{\mathrm{align}}
=\frac12L_{\mathrm{align}}^V
+\frac12L_{\mathrm{align}}^P
\]

总损失沿用现有顶层权重：

\[
L_{\mathrm{total}}
=0.85L_{\mathrm{anchor}}
+0.15L_{\mathrm{align}}
\]

分别记录两类预测损失、两类对齐损失和总损失。

训练实现需正确处理有效样本数、标签 mask、样本对 mask 和梯度传播。响应标准误与设计权重的具体使用方式以检查后的实际损失实现为基础，并在验收报告中明确记录。

## 6. 反向传播

每个训练 batch 中：

1. 计算共享 z、t、b；
2. 生成256维条件化输入；
3. 分别预测 VIIRS 与 POI 响应；
4. 计算两个响应预测损失和两个响应对齐损失；
5. 组合为联合总损失；
6. 执行一次反向传播和优化器更新。

两个预测任务共同更新同一份 State Encoder 参数。

具体而言：

- VIIRS 预测损失更新 VIIRS 预测头，并通过共享输入更新各可训练编码模块；
- POI 预测损失更新 POI 预测头，并通过共享输入更新同一组编码模块；
- 两项响应对齐损失共同塑造 z；
- 冻结的 DINOv2 主干保持冻结；
- DINOv2 后续投影、注意力聚合、卫星 CNN/GRU、表格编码器和融合网络参与正常训练。

沿用现有 AdamW、学习率调度、梯度裁剪和 checkpoint 选择机制，并根据联合训练的实际表现调整训练参数。

## 7. 验证方案

### 7.1 功能测试

验证以下张量形状：

```text
z                 [B, 128]
t                 [B, 32]
b                 [B, 96]
concat(z, t, b)   [B, 256]
tau_hat_viirs     [B, 6]
tau_hat_poi       [B, 12]
```

验证以下行为：

- 固定 S，改变 T 或 C 时，z 保持不变；
- 两个预测头都能正常前向计算；
- 两项任务都能产生有效梯度；
- 两项损失共同更新同一个 State Encoder；
- 部分标签缺失时，其他有效任务仍能正常训练；
- checkpoint 保存和加载后，模型结构及预测输出保持一致。

### 7.2 科学评估

至少完成以下比较：

1. 联合训练模型：共享 State Encoder + 两个响应预测头；
2. 原有 VIIRS 与 POI 独立训练模型；
3. 联合训练的 Anchor-only 消融；
4. 仅使用 T、C 的条件预测基线；
5. 仅使用 z 的状态预测基线。

评价指标分别针对 VIIRS 和 POI，包括：

- 响应预测误差；
- 相对于平均响应基线的性能提升；
- 独立测试集上的近邻响应一致性；
- 响应检索质量；
- 未见城市上的预测与迁移表现。

沿用城市级训练、验证和测试划分。标准化参数只由训练集计算，验证集用于模型选择，测试城市用于最终评估。

### 7.3 模态消融

在联合训练框架下评估：

- 完整多模态状态输入；
- 去掉街景；
- 去掉卫星序列；
- 去掉图像模态，仅使用表格历史。

比较两项响应任务的预测、检索和跨城迁移表现，以衡量各模态的实际贡献。

## 10. 2026-10-22 确定性补充（优先于前文未明确的表述）

### A. 有效任务损失归一化

Anchor 分别计算 VIIRS/POI 有效标签损失。两项有效时严格0.5/0.5；仅一项有效时权重为1；均无有效监督时跳过 batch 的监督优化器更新。Alignment 独立判断每族有效样本对，仅平均当前具有有效对齐监督的任务。缺失标签、零有效样本对、除零与NaN必须显式处理并有单元测试。

### B. AlphaEarth 背景编码

有效 AlphaEarth64直接保留，表格编码32，拼接为b96，不整体L2归一化。缺失时使用64维缺失表示并显式编码可用性，输出维度始终96。记录AlphaEarth与表格分支的数值尺度及梯度贡献。

### C. 同架构单任务对照

VIIRS-only、POI-only、Joint三组均使用z128/t32/b96/x256、同一联合数据schema、同城市划分与预处理。每个任务在同测试城市和同有效标签上比较预测误差、响应检索、近邻一致性及跨城泛化。旧模型作为历史参考保留。

### D. 梯度裁剪与诊断

增加可配置全局范数裁剪；记录裁剪前联合范数、两任务对共享State Encoder的各自梯度范数与相对方向/冲突。诊断不得改变实际训练梯度。裁剪阈值、诊断频率和统计写入配置与日志。测试必须证明两任务均能更新同一State Encoder且裁剪正常生效。

完整实施顺序、文件清单、边界策略及验收标准见[实施计划](stc_joint_training_plan.md)。功能与小规模训练验证完成后，最终报告必须列出修改文件、测试结果、三组实验状态和未完成事项；fixture smoke不得充当正式科学评估结果。
