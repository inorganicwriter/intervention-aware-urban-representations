## 汇报结论的强度

可以讲：因果响应可组织成可追溯学习目标；处理前特征有弱的城市外预测信号；VIIRS历史监督嵌入有初步检索增量；POI结果推动更细的outcome分析与几何保持方案。

仍需检验：神经表示在统一城市CV下的稳定增量；响应块融合的内层选参、外层配对成绩；在新站点或新城市未观测效应时的实际规划价值。
