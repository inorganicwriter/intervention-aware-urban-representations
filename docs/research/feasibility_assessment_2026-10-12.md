## 值得继续推进的证据

1. 研究问题可以落实为可检验任务：给定处理前特征与站点属性，预测未见城市中的估计响应轨迹；与同协议简单模型比较，不依赖可视化叙事。
2. 既有事件研究能够提供有规模的经验基础。Matching 的 VIIRS 有 2,267 个可用事件、43 城；POI 有 2,478 个可用事件、44 城。这些是对应分析组合的数量，不是完整多模态合格训练样本数。
3. 五折城市对照的服务器报告显示，Raw Ridge 的 VIIRS RMSE 为 0.3627，训练均值为 0.3748，相对降低约 3.23%；POI 为 0.4442 对 0.4642，约降低 4.31%。这支持“特征可能含有可预测信号”，增益仍需逐城市区间和正式复现确认。
4. 数据管线有较明确的冻结、版本和来源边界，因果估计与下游训练分离，便于在保留历史研究记录的情况下构建修正版。
5. 已有工程测试通过，视觉骨干冻结、小型任务头和离线特征缓存适合当前千级事件规模。工程可运行和研究有效是两项不同验收条件。

**1. 主实验前修正：卫星覆盖率与处理前合法覆盖率分开统计。**

实测 AlphaEarth 共 5,048 行、44 城、5,048 个唯一 treatment_order，64 个波段均为有限值，无全零行。但有 **1,751 行（34.69%）** 的 `target_year >= opening_year`，全部属于代码定义的 temporal proxy；真正满足目标年度早于开通年度的只有 **3,297 行（65.31%）**。

提取器将 `opening_year - 1` 截到不早于 2017；2010—2017 开通的事件因此使用 2017 年嵌入。2017 年开通的事件也不合法，因为年度嵌入包含全年观测，可能包含开通后的变化。[Google 官方数据说明](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL)确认了 2017 起的年度产品及全年汇总性质。

下游 `attach_satellite_embeddings` 只保留 treatment_order、波段及 available，丢掉了 target_year 和 proxy 标记；Dataset 加载波段时也不按开通时间检查。这使不合法影像能够作为可用卫星输入进入训练，而不只是元数据中标注的一项局限。

建议主实验对这些事件屏蔽卫星分支，或单独建立 2018 年及以后开通、拥有完整前期与后期结果支持的严格样本。早期事件可使用合法历史影像或表格分支；使用事后代理的实验只能独立标记为回顾性探索。3,297 是时间合格卫星事件的上限，还须与同城 Matching/GSC、结果 horizon 和街景交集核对，不能直接当作训练 N。

这项修正不要求删除所有早期事件、重新采集全部数据或重估整个因果标签库。先通过模态掩码或严格子样本建立可运行版本，其他模态及既有合法数据可以继续使用。

证据：`scripts/collection/extract_alphaearth_embeddings.py:75`；`src/urban_intervention/causal/pretraining_dataset.py:353`；`src/urban_intervention/representation/dataset.py:237`。

**2. 新方案主实验前贯通：将已定义的新损失接入正式训练。**

`loss.py` 已定义 design-weighted Huber 和 `multimodal_causal_loss`（0.85/0.15）。正式 `trainer.py` 的训练/验证，以及候选 `training/epoch.py`，仍调用 `total_loss`；其预测项为平方误差，默认 `pred_weight=0.5`，表示项仍保留旧对齐与距离组合。

因此，文档所称新 Soft Causal Anchoring 训练已经完成接入，与实际主路径不符。`streetview_pipeline.md` 的 `--use-multimodal`、`--loss-anchor-weight`、`--loss-align-weight` 也不存在于当前 CLI；实际有 `--use-images`、`--use-satellite` 和 `--use-cross-view-synergy`。新 Level 1/2/4 函数在本次全库搜索中只见定义和单元测试调用，没有正式报告调用。

建议先以一个真实小批次贯通 Dataset→主训练器→新 loss→checkpoint→报告，验证配置和梯度实际来自新目标；随后补齐文档及现有集成验证。0.85/0.15 是系数，不保证对应 85%/15% 的梯度贡献，仍需记录损失尺度。

这是训练链路的实现差距，不是否定 Soft Causal Anchoring 的方法判断。旧目标仍可作为明确标注的对照；采用新目标的实验须先完成接入，不应仅凭函数单元测试宣称正式训练已升级。

证据：`src/urban_intervention/representation/trainer.py:150`；`loss.py:299`、`:356`、`:407`；`cli.py:116`。

**3. 后续架构增强：当前池化融合与空间寻址目标存在差距。**

提取器以 `ee.Reducer.mean()` 将网格内 AlphaEarth 像素压成一个 64 维向量，Dataset 的 batch 为 `(B,64)`。正式模型先把街景池化为一个向量，再把两侧送入注意力。文档描述的 `(B,S,64)` 卫星场和 DINO patch token 序列在这条路径中并不存在。

当 Key/Value 只有一个 token 时，softmax 权重恒为 1，注意力的寻址输出不随 Query 改变。实测单 token 注意力权重均为 1，替换地面 Query 后 attention-output 最大差异为 **0.0**。残差和后续网络仍能融合两种信息，但这不能作为“地面视角在卫星空间场上寻址”的证据。

全景当前直接缩放为 224×224，再读取 DINO 全局向量；没有正式接入全景透视投影切片或 patch 序列。优先可将实际方案明确为 pooled-feature fusion，比较拼接/Ridge/小 MLP。如果空间交互确有额外收益需求，再增加卫星 patch token、位置编码及全景切片，先控制 token 数与样本规模。

池化特征融合本身是可行的第一阶段多模态方案，可以直接开展响应预测和跨城迁移研究。无需先建成稠密空间注意力才能推进项目；只有要声称模型实现了空间寻址，或检验空间交互带来的额外增益时，才需要补齐 token 和空间结构。

[VIGOR 原论文](https://openaccess.thecvf.com/content/CVPR2021/html/Zhu_VIGOR_Cross-View_Image_Geo-Localization_Beyond_One-to-One_Retrieval_CVPR_2021_paper.html)研究的是跨视角地理定位及非一一对应检索；它提供跨视角研究背景，不能单独证明当前注意力结构或因果响应任务的有效性。

证据：`scripts/collection/extract_alphaearth_embeddings.py:149`；`encoder.py:282`；`model.py:272`；`dataset.py:83`。

**4. 主实验前明确口径、并行审计：按方法和指标报告监督诊断。**

最终发布中的同城 Matching 联合预趋势 p 值：VIIRS 0.063052、POI count 0.071692。在 5% 水平不拒绝，在 10% 水平会拒绝；都不能解释成平行趋势已经被证实。预检验低功效及依检验筛选结果带来的偏差已有明确方法依据，见 [Roth, 2022](https://www.jonathandroth.com/assets/files/roth_pretrends_testing.pdf)。

更直接的问题是，同城 **POI–GSC** 的城市聚类“处理前平均 gap 为零”检验已经记录了偏差：

| outcome | 城市聚类 p 值 | 5% 水平诊断 |
|---|---:|---|
| poi_count_log | 0.216534 | 未拒绝 |
| poi_category_entropy | 0.048247 | 拒绝 |
| poi_commercial_share | 0.000863 | 拒绝 |
| poi_transport_access_log | 0.000654 | 拒绝 |

这些是平均 gap 检验，不能与 Matching 的联合趋势检验混称；但后三项直接表明尚有处理前不平衡，不能将整个 POI 同城 GSC 12 维向量都写成已验证可靠监督。族级 `family_selection` 只以 canonical outcome 摘要，不能替代每个 outcome 的诊断。

可先以 VIIRS 和 POI count 作为较容易解释的主结果，同时保留其他 POI 维度的探索训练和逐 outcome 分析；不要求一次性取消全部 POI 多任务监督。对已出现处理前不平衡的组合，按既定设计诊断规则明确主分析或敏感性分析角色，完整保留筛选记录和全样本对照，避免根据显著性事后挑结果。其他维度的审计、提前反应、1/1.5/2km 排除半径及竞争开通事件分析，可与已有支持任务的训练并行推进。

证据：`outputs/event_study_final/pretrend_summary.csv`、`family_selection.csv`、`availability.csv`。

**5. 当前方法设定与并行核查：使用带噪响应监督，逐步补充不确定性与外推验证。**

每个网格的 `observed - estimated counterfactual` 混合了效应、结果波动和反事实误差。地铁规划、提前开发、同期 TOD、商业建设及跨网格溢出都可能影响反事实假设。好的 pre-fit、可靠性权重和 Huber 可以改善稳定性，不能自动去除共同的系统偏差。

带噪标签是本研究的合理起点，Soft Causal Anchoring 正是在这一设定下工作的方案。无需先消除全部估计噪声或获得不可直接观测的个体因果真值，才能开展表示学习；应将估计响应与潜在真实效应区分，检验可靠性权重和稳健损失是否改善迁移，并报告适用范围。

2026-10-07 的重算说明还明确指出：轨道快照被上游控制设计读取，旧历史邻接缺少有效边日期。服务器发布究竟使用哪版快照仍需核查；现有材料不能证明全部标签已受影响，也不能证明全部不受影响。先核对实际发布来源和输入指纹，再决定受影响范围，保留冻结标签，修订另建版本。

如果要外推到规划尚未开通站点，应同时核查预测时点早于开通多少年、哪些站点属性当时已知，以及目标地区是否落在历史事件支持范围内。开通前一年预测并不等于规划决策阶段预测；跨城市验证也不等于跨年代未来事件验证。

历史快照的来源核查应尽早并行开展；只有确认具体标签版本受到影响，才确定其修订范围。当前可以继续明确标注的冻结版本探索实验。年份隔离和规划时点验证用于逐步扩展研究结论，不必全部完成后才启动跨城预测实验。

**6. 当前规范命名、后续扩展机制：区分响应方向与置换/士绅化标签。**

当前 `planning_semantic_classification_metrics` 将平均响应 `>0.05 / [-0.05,0.05] / <-0.05` 映射为 activation/no response/displacement。负灯光或负 POI 响应本身不能识别小店挤出、居民迁出或士绅化，固定 0.05 也未按不同 outcome 的单位和不确定性校准。POI 数量、熵、商业占比和交通相关指标混合求平均，还会混淆不同构念。

建议现阶段命名为“正向/弱或不确定/负向估计响应”，按 outcome 独立定义阈值并报告估计不确定性。要恢复置换或士绅化主张，需要企业/店铺身份、进入退出、租金、居民或商业结构等额外证据。年度 POI 存量不能直接推出新增/退出率。夜间灯光可作亮度响应代理，尚需外部证据才能解释为消费或夜间经济响应。

规范命名后，响应方向分类和表征研究可以继续推进。新增机制数据属于扩大研究目标时的工作，不应成为当前 VIIRS/POI 响应预测的启动条件。

证据：`src/urban_intervention/representation/evaluation.py:649`；《研究思路.docx》。

## 对已有模型结果的判断

旧分城测试的汇总显示：VIIRS raw 检索 0.0036，监督模型 0.0150±0.0067（3 seed SD）；POI raw 0.1089，监督模型 0.0955±0.0025。VIIRS 有数值增益，但 seed 波动、城市相关性与 AE 对照使其尚不能构成稳定优势证据；POI 的旧监督结果低于原始特征。seed SD 不是置信区间。

五折 Raw Ridge 对训练均值的 3.23%/4.31% RMSE 改善是继续验证的合理依据。它既不证明深度多模态模型必胜，也不证明低维特征已达到上限。“27 维扩到 128 维”并非数学上不允许；非线性表示能展开特征。输入像素更多也不自动保证更好的响应预测或信息瓶颈。新增模态是否提供与响应有关的额外信息，应由公平消融实验决定。

正式主协议应固定城市五折、折内预处理/选参、三个随机种子和城市宏平均；同样报告 pooled 指标及逐城市配对增量。先用固定训练/验证城市的小规模实验确认实现和信号，再开展该主协议。按开通年份隔离的验证用于后续检查时间外推。不同模型必须使用相同测试事件、同样的结果支持掩码和同样的信息截止日期，不能让多模态模型因样本筛选而获得较容易的测试集。

## 最小可行研究方案与验收条件

建议先回答一个问题：**严格使用开通前信息时，多模态输入能否提高未见城市中 VIIRS/POI count 的估计响应预测？**

| 阶段 | 具体交付 | 继续推进条件 |
|---|---|---|
| 数据与来源审计 | 每城×开通年×标签族的时间合法覆盖表；街景存在/可解码/前期日期凭证；标签来源核对 | 主实验无同期或事后影像；能说明每个最终 N 的筛选来源 |
| 工程贯通 | 新损失真实进入训练/验证/报告；可复现命令；单 token 融合如实命名 | 一个真实小批次完成训练与导出，loss/模态/来源记录可核对 |
| 最小基线 | 训练均值、Tabular Ridge、Tabular+AlphaEarth Ridge/小 MLP、加入街景的简单融合 | 相同样本和城市划分，折内调参；确认额外模态有预测增量 |
| 表征主实验 | 简单融合 vs 响应监督融合；弱对比项的独立消融 | 固定协议后，城市宏平均误差及逐城市配对增量提供稳定优势证据 |
| 增强与外推 | 有空间 token 的注意力、年份隔离验证、不确定性及支持范围报告 | 增强模块相对简单融合有可重复的新增价值；未来事件验证不明显失效 |

先在固定训练/验证城市做一个 pilot 检查数据和实现，预先确定主配置，再锁定 outer CV。不要看多个 outer-test 结果反复改模型、改阈值和挑指标。成对样本数量 O(N²) 不会使独立干预事件增加到 N²；城市、线路和开通批次才是评估不确定性的重要层级。

若简单多模态回归优于表格，但表征/注意力没有额外增益，可形成“多模态特征支持响应预测”的较窄论文结论。若连简单多模态回归也无稳定增益，应停止持续扩大网络，把成果转为干预响应数据库、异质性分析与可迁移性边界。这样的转向有研究价值，但发表潜力仍取决于识别、数据与论证质量。

## 资源与工期

按项目记录的 4×RTX4090、冻结 DINOv2 和千级事件规模，当前路线的主要约束更可能是历史影像覆盖、数据核查和实验协议，而非 GPU 总量。优先离线缓存合法街景特征，避免每个 epoch 经 NFS 重复解码。现有纯表格 smoke 的显存数字不能外推到全景 patch 和卫星空间 token 路径；后者需独立 profiling。

工作量估计（假设服务器数据和执行权限已就绪，并行 GPU 仍可用）：数据/来源与接线核查约 3—5 个工作日，最小基线与固定协议约 3—5 个工作日，正式 CV、消融和不确定性约 1—2 周。建议先投入 **2—4 周** 获取是否存在稳定增益的决策证据，不承诺完整论文时间。若历史街景缺失或标签需要重新估计，需重新评估工期。
