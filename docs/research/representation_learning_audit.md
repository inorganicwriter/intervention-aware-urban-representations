## 结论与证据边界

当前最值得优先处理的是**相似度目标与损失的几何不一致，以及评估协议的识别能力**。现有结果说明当前监督训练没有稳定、可复现的增量；尚不能说明处理前特征没有可预测信号，也不能把失败归因于参数量或标签本身。

本审计使用当前仓库源码、用户提供的服务器实验简报，以及本地小型数值实验。服务器指标是用户转述，未读取其训练文件或重新运行服务器实验。每个网格只有一种估计方法，matched/GSC 互斥，因此多方法覆盖同一 cell 不是当前问题。因果标签冻结，不重算标签，不做数据增广。此次仅新增审计文档与诊断产物，未修改训练实现。

实际 CLI 导入 `representation/trainer.py`；`training/` 和 `trainer_modular.py` 是候选模块化实现，不是默认入口。下面的主要问题存在于两条路径共用的模型、损失及评估函数。

## 1. 最强证据：两个表示目标要求不同的几何

位置：`src/urban_intervention/representation/loss.py:144–159, 186–192, 229`。

设响应相关性为 r，嵌入余弦为 c。当前软对比目标是：

\[
q_{ij}=\frac{\max(r_{ij},0)}{\sum_{k\ne i}\max(r_{ik},0)},\qquad
p_{ij}=\mathrm{softmax}_j(c_{ij}/\tau).
\]

对比损失要求 p 接近 q，因此两个正候选之间应满足
\(c_{ij}-c_{ik}\approx\tau\log(r_{ij}/r_{ik})\)。距离损失同时要求 \(c_{ij}=r_{ij}\)。一般不能同时满足。例如 r 分别为 0.9、0.5，软标签概率比为 1.8，而 c=r、τ=0.07 时模型概率比为 exp(0.4/0.07)≈303。

**实际调用当前实现的数值反例：**构造三个完全观测、中心化响应向量，把它们本身归一化作为 oracle 嵌入，余弦恰好等于响应相关性。

| 嵌入 | 对比损失 | 距离损失 | 当前 0.5/0.5 表示损失 |
|---|---:|---:|---:|
| oracle，精确匹配响应几何 | 1.67045 | ≈0 | 0.83523 |
| 三个嵌入全部相同 | 0.69315 | 0.10124 | **0.39719** |

这是一个方法反例，不是服务器塌缩的实证。它说明“代码正确、loss 下降”不能保证朝研究目标优化。POI 模型经常低于原始几何，与这种破坏弱信号的机制相容，但还需实测嵌入有效秩、平均余弦、成对梯度方向才能确定实际贡献。

优先对照是直接回归响应、以及保留原始几何的混合检索。若保留相似度蒸馏，可将 teacher 改为同一尺度的 `softmax(r/τ_target)`，用 KL 对齐 student；温度一致时 c=r 可使 KL 为零。它是待验证方案，不保证迁移提升；缺失观测造成的不可实现几何仍需处理。不建议继续重复已经不稳定的温度/queue 单 seed 搜索。

## 2. 响应相关性与“干预响应相似”不是同一个概念

位置：`representation/evaluation.py:110–177`。

### 2.1 相关性忽略水平、大小，甚至响应符号

当前实现将 `[0.1,0.2,0.3]` 和 `[-0.3,-0.2,-0.1]` 的相似度算为 **0.999999**。两条路径走势相同，但一条始终受益，一条始终受损。Pearson 的平移/正比例不变性是定义性质；若论文目标仅为曲线形状，这可以成立。若目标是响应方向和幅度的可迁移预测，就与预测头要求区分这些样本形成张力。

建议同时报告形状检索、响应方向与逐 outcome 幅度误差，并明确主目标。可以在下游目标里比较 train-only 标准化响应距离、无中心化余弦或响应摘要；无需改动因果估计值。不要通过更换指标后只保留好看的结果。

### 2.2 POI 的 12 维混合了不同构念和尺度

实现按 family 切片，POI 的四个 outcome × 三年被放在同一个 Pearson 中。log 数量、熵、商业占比、交通可达性是不同量纲/构念；跨 outcome 水平可能主导“相似”，并不等于时间响应相似。预测 MSE 同样未按 outcome 的训练尺度校准，误差尺度较大的 outcome 会占更多梯度。

用户给出的 POI 跨 outcome 折半相关低，支持“统一相似度缺乏一致结构”的怀疑，**不能直接解释为每个 outcome 的标签都不可靠**。Spearman–Brown 结果是否能当作信度，需要先确认两半是同一构念的平行测量；异质 outcome 分半不自然满足这一前提。

先对四个 outcome 分别检查信号、检索和预测，再决定是否等权汇总。每个 outcome 只有三期，逐 outcome Pearson 也很不稳定，因此 per-outcome 不是自动修复；可优先直接回归原始三期标签，或下游汇总效应水平/趋势，保留冻结标签。

### 2.3 两个公共 cell 被当作充分证据

两点 Pearson 在非退化时只能为 +1 或 -1。当前 `common>=2` / `reliable>=2` 将它们直接纳入训练、检索，未按公共支持数量或相关性估计方差降权。诊断复现 `[0.001,0.002]` 与 `[100,101]` 相似度为 1。

服务器应先统计两点、三点、完整支持 pair 的比例，以及各支持层的指标。VIIRS 可考察 >=4 个公共 horizon 的敏感性；POI 逐 outcome 最多三点，不能套用同一门槛后把所有样本删掉。

不同 pair 使用不同 cell 子集，相关矩阵还可能不是半正定。诊断构造的三条响应得到三对相关性均为 -1，矩阵最小特征值为 -1；单位嵌入余弦矩阵无法精确实现该目标。这不是服务器已发生的事实，而是 pairwise deletion 的结构风险。应检查实际支持模式与目标矩阵负特征值规模。

## 3. 权重的实际作用比文档描述弱

位置：`representation/loss.py:17–41, 144–159, 281–296`；`evaluation.py:127–158`。

### 3.1 SE 收缩不等于给噪声样本降低 loss 权重

当前 r' = r·sqrt(a_i a_j)，a_i=mean(1/(1+SE²))。正样本再按行归一化时，anchor 的 sqrt(a_i) 因子消失。其噪声不会因此降低该 anchor 在最终均值中的权重；候选可靠性改变了相对正样本分布，却没有降低噪声负样本的 softmax 作用。

所有 SE 从 0.1 改为 100，诊断中的 InfoNCE **完全相同：5.239387**。距离项仍以相同权重把目标往零推，等价于要求高噪声 pair 更接近正交，而非忽略它们。另外 `1+SE²` 依赖响应单位；没有信号方差参照，不能解释为校准过的统计可靠性。

合理的下游修复方向是把“目标定义”和“pair/anchor 置信权重”分开，并按训练池尺度校准不确定性。具体置信权重需做验证，不宜将缺失 SE 自动解释为高可靠性。

### 3.2 样本级设计权重可能在 Pearson 中抵消

若一个样本所有 horizon 的设计权重相同，pair 每个共同 cell 都乘同一常数，weighted Pearson 与 unweighted Pearson 完全相同。诊断把样本权重从 0.001 拉到 1000，相关矩阵最大变化仅 **6.7e-16**。

这对单 outcome VIIRS 尤其值得核实：若设计诊断在各 horizon 重复，W-design 对表示相似度可能几乎不起作用。POI 跨 outcome 权重可改变相关结构，但仍不是降低低质量 pair 的整体贡献。预测损失确实使用设计权重，这一点没有失效。

另外，loader 总会传 `response_weight`，即使旧数据也补为 1。因此实际预测路径采用 design-weighted MSE，不进入历史 `1/SE²` 分支；`docs/research/representation_learning.md` 对预测 SE 加权的描述滞后。更细的 `label_reliability_weights.md` 与实现一致，这是口径差异而非意外漏传。

## 4. 站点条件化存在可复现的尺度问题

位置：`representation/model.py:87–90, 191–209`；`dataset.py:159–170, 439`。

地点编码器先输出范数 1 的向量，直接加上默认初始化的 128 维 token embedding 后再归一化。诊断中 token 范数 **10.95**；同一 token 的 32 个地点，表格流平均成对余弦从 **0.6697 升为 0.9973**。这会在初始化阶段严重压缩地点差异；最终投影后是否持续塌缩需要服务器实测。

这也使现有单 seed station 结果不能充分检验“站点属性有用与否”。可优先用四个 bit 的数值输入、连续属性和显式缺失指标，再经训练池标准化；或者用小初始化、受控残差门控，使初始条件化保留地点差异。

现有 token 只读取四个布尔属性，没用 `n_lines_at_opening`、`same_month_openings`、`same_month_new_line_stations`。缺失属性 fillna(0)，整行缺失也映射 token 0，未知与“四项均否”无法区分。

## 5. 现有 probe 不足以证明特征可预测性上限

位置：`representation/evaluation.py:399–451`。

当前 ridge 没有截距，也没有对 x、y 做训练均值中心化。同样的 lambda=1 用在单位范数嵌入和 z-scored 原始特征上，其正则强度并不等价。

诊断使用中心化 x 与常数 y=2，当前 probe RMSE 为 **2**，训练均值基线为 **0**。这是评估实现的真实限制，会影响 raw/embedding 对照；影响方向取决于具体特征均值、尺度及目标分布，不能预断有利于哪一方。

优先修正：有截距（或训练池中心化）、各表示独立的 inner-city-CV ridge 选择、训练均值基线、按 outcome 报告误差。再加一个受约束的非线性直接回归基线，区分线性 probe 不可预测与 X 本身不可预测。不要以一次固定 ridge 或线性探针代替可预测性上限实验。

VIIRS 标签一致性约 0.8，只说明标签有可重复结构，并不意味着 X 包含该结构。相反，“raw probe≈embedding probe”也不能证明两者都达到了上限。

用户报告的 VIIRS 模型均值 0.015 确实高于 raw 的 0.0036；准确表述是**增量未获稳定统计支持且未稳定超过 AE**，而不是数值上从未超过 raw。POI 则已有更一致的“不如原始几何”证据。

## 6. 评估应先恢复判断能力，避免继续消耗小 test

位置：`representation/trainer.py:831–840`；`evaluation.py:304–380`。

- checkpoint 按 total loss 选择，目标与检索不一致；变化 0.002 的原始 val loss 不是有意义检索增量的保证。
- 对比交叉熵含软标签熵 H(q)，候选池大小、queue 长度会影响其不可约部分。不能把 train/val 的 loss 差直接解释为过拟合；learnable temperature/uncertainty weighting 的 loss 也不适合跨运行直接比大小。
- test 仅 205/220 个网格，独立信息量取决于城市/线路/开通批次相关性，通常不能按 205/220 个独立观测解释。
- 当前 bootstrap 重采样已固定的 anchor 分数，不重建邻居，也不处理城市簇；全局 permutation 会打散城市结构。它们不能直接回答“新城市是否稳定优于 raw/AE”。
- 多 seed 处理优化随机性，不能替代城市划分的不确定性。

建议冻结当前 test 结果为探索性结果，预先固定 **5 折城市级 outer CV、inner 城市验证、每配置 3 seeds**。按可用标签覆盖平衡城市折，但保持同城不跨折；报告各城样本与支持数量。若预算不足，减少配置数量，而不是退回单 seed。

每折按城市宏平均评价，同时保留 pooled 指标；直接统计同一城市/anchor 上模型减 raw 的配对增量，给出城市簇或开通批次的敏感性区间。少城市时明确区间不稳定。permutation 应按要检验的零假设考虑城内/批次约束；一个全局显著 p 不代表胜过 raw，也不代表迁移。

在 inner validation 固定选点规则。可选城市宏平均检索增量，或训练前锁定训练长度；不要看 outer test 后挑 epoch，也不要从大批试验里事后挑“固定 epoch”。

## 7. 额外实现风险：float32 相关性消减误差

位置：`evaluation.py:145–177`。协方差/方差由 `sum(x²)-sum(x)²/n` 计算，在几乎平坦但有非零水平的路径上会发生消减。

诊断用 32 条六期曲线、水平 0.5、期内波动 sd=1e-4。对相同的 float32 输入转为 double 后比较：double 判定有效的 992 个有向 pair，float32 丢失 **860 个**，相似度平均绝对差 **0.426**。水平 0.1 的另一组平均绝对差约 0.096。普通相似度单元测试没有覆盖这种尺度。

这是可复现的计算风险；尚不知道服务器是否有足够多这类平坦响应。应统计响应的行内方差/水平比，再以 float64 标签相似度或稳定中心化计算复核。只涉及下游数值计算，不改变因果标签。

网络 closeness 的风险有明确源码证据：`build_transit_snapshots.py:105–106` 是 CURRENT full network，`:260` 每城只计算一次，`:147` 只过滤站集合。未来站点/边仍参与早期站的最短路径。距离/站数和 closeness 不能捆绑视作同等时间合规。若接入表示学习，独立重建处理前图上的特征即可；本建议不要求重算因果标签或改动既有估计。

## 9. 保留原始几何、附加少量响应信息的具体方案

令 x 是训练池标准化后的原始特征并逐行单位化，h 是直接响应回归得到的紧凑表示/预测摘要并单位化：

\[
z_\lambda(x)=\left[\sqrt{1-\lambda}\,\bar x,\;\sqrt{\lambda}\,\bar h(x)\right].
\]

两块范数均为 1 时，余弦恰为
\((1-\lambda)\cos(x_i,x_j)+\lambda\cos(h_i,h_j)\)。因此 λ=0 精确恢复 raw 检索，而不是让监督任意改写 raw 几何。零向量需定义回退规则。

只在 inner validation 比较预先给定的少量 λ（含 0）；outer test 不选 λ。**仅 λ=0 有逐点等同 raw 的保证，λ>0 或按验证选择的模型都不能保证 test 不劣于 raw。** 如果大多数城市折选择 0，这也是监督增量不足的直接证据。

相比重构+监督，这个方案更容易解释和归因。重构只约束信息可恢复，不保证近邻几何不变；现有 AE 对照也不构成重构联合训练一定有效的证据。

## 10. 最小实验集与停止规则

先修 probe、稳定相似度计算、条件化尺度；做公共支持/有效秩/设计权重抵消的诊断，保留当前服务器结果作为历史对照。随后在固定城市 CV 协议下，只保留以下有明确判别目的的配置：

| 配置 | 用途 |
|---|---|
| raw 检索 + 有截距 ridge + 训练均值预测 | 恢复可信基线 |
| 原始 X 的小型直接回归模型（另配一个非线性对照） | 检验 X 对冻结响应标签是否存在 out-of-city 可预测性 |
| 当前监督模型 | 验证历史结果在新协议下是否稳定 |
| raw + 紧凑响应块（λ 包含 0） | 检验保留几何是否避免 POI 负迁移 |
| 上述简单模型加入已审计的轨道/站点属性 | 检验缺少干预结构信息的假说 |

POI 逐 outcome 分析贯穿所有配置。128 维/约 **125,147** 个参数可能过大，但参数数目本身不能证明过拟合；用训练/城市验证误差、学习曲线和小模型对照判断。pair 数 O(N²) 也不等于独立监督样本增加到 N²。

queue 当前保存在线模型产生的旧 detached embedding，没有 momentum encoder；历史表征漂移是合理风险，既有 queue=0 未稳定解决说明它不是充分解释。[MoCo 原文](https://arxiv.org/abs/1911.05722) 用动量编码器提高队列一致性，但不意味着本任务必须改成 MoCo。在新的主实验里暂用无 queue 简化归因，不重复以大队列为默认增益假设。

**判别顺序：**修正评估后直接回归可预测、当前嵌入仍差，优先归因于目标/压缩；仅加入轨道属性后改善，优先归因于原特征缺信息；简单/非线性模型、新增属性、几何保留方案均无稳定城市外增量，才支持“现有可观测特征下监督增量有限”。不把后者推广为所有表示学习均不可能。

如果最终是负结果，论文可围绕冻结的干预响应估计与异质性证据展开，将表示学习作为系统性的可迁移性边界检验。需报告城市、outcome、标签支持及特征条件，不宣称已构建优于外观的可迁移响应表示，也不通过事后换指标维持原主张。
