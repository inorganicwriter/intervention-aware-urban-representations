## 输入角色

| 角色 | 内容 | 模型用途 |
|---|---|---|
| 状态 `S_i` | POI 结构与历史特征、基线 VIIRS、街景、独立卫星图像 | 状态编码器生成唯一的多模态状态 embedding `z_i` |
| 干预 `T_i` | 开通年份、开通时站点类型、线路数、同月开通规模，以及对应可用性 mask | 干预编码器生成响应预测条件 `t_i`；站点到格心距离仅作为可选空间特征，见下节建议 |
| 背景 `C_i` | 完整 AlphaEarth `A00`–`A63`、开通前人口、城市统计背景（房价字段不进入背景） | 背景编码器生成响应预测条件 `b_i` |
| 监督 `tau_QE_i` | 当前验收范围内的 VIIRS 与 POI 准实验响应及可靠性权重 | Soft causal anchoring 与响应对齐，不作为预测特征 |

`C_i` 在此表示多尺度背景，包括网格局地背景和所在城市背景。单个处理网格的 AlphaEarth 向量属于局地背景，不能直接称为全市背景。城市统计量应从相应范围的数据构造，不能把处理网格样本平均值直接当作有代表性的全市统计。

路网不进入本轮状态或背景，不新增路网采集作为本轮前置任务。既有道路可达性指标也不因属于普通数值列而自动加入模型，正式字段按输入角色白名单确定；站点干预描述与路网状态数据分开管理。

状态中的“卫星图像”指独立影像 patch 或由这些影像独立编码的视觉特征。背景中的 AlphaEarth 指已有的 64 维预训练嵌入，两者使用不同字段与编码器。不能将同一 AlphaEarth 向量复制到状态和背景以声称已接入独立卫星图像。输入角色的分离不意味着二者在信息上独立；遥感信息的重叠通过消融比较评价。

房价和人口曾被排除在正式响应监督之外。当前背景输入只保留人口与城市统计；房价字段已从背景 `C_i` 中移除，不再进入 ContextEncoder。缺失值保留可用性 mask，不要求每个事件拥有全部背景数据。人口产品口径与房价来源仍随数据保留，但房价不作为本轮模型输入。

## 干预输入 `T_i` 的细化建议

干预分支描述“在哪个时间，以什么形式、规模，作用于该网格的地铁开通事件”。下表是本次字段建议，不表示已有模型已接入全部字段。根据本地数据与空间规则核对，第一版采用开通年份、四个类型属性和两个规模字段，共七个基础字段，另保留可用性 mask。审阅结果见 [干预输入资产与空间单元核对](intervention_input_availability_audit_2026-10-12.md)。

| 信息 | 第一版建议字段 | 现有来源与接入状态 |
|---|---|---|
| 开通时间 | `opening_year` | 处理事件表有 `opening_date`、`opening_month`；当前模型已有开通年条件接口。原始日期与月份保留用于状态截止、响应窗口对齐，月份编码可作为后续比较。 |
| 开通时站点类型 | `is_transfer_at_opening`、`is_new_line_opening`、`is_extension_opening`、`is_terminal_at_opening` | 2026-10-13 已生成 `station_attributes.parquet`，并发布七字段 `intervention_grid_v1/`。原始终点有 783 个未知；另一个无合法线路数的事件相关类型字段也屏蔽，最终终点可用 4,264 个。新线与延伸可能同时成立，不做互斥类别。历史来源仍需审阅。 |
| 干预规模 | `n_lines_at_opening`、`same_month_openings` | 已发布，线路数为 0 的 `treatment_order=3537` 使用缺失 mask，线路数可用 5,047 个；同月开通数可用 5,048 个。当前站点条件接口未消费这些数值。后者是同一城市、同一日历月开通的站点实体数量，包含该站，不能当作网格附近新站数。 |

`distance_to_opening_station_m` 从第一版核心干预字段调整为可选空间特征或消融项。正式处理单元是城市固定 500m × 500m 网格，站点通过点落入多边形规则绑定到所在格子，网格不逐站重定位。5,048 个事件均可匹配网格中心，站点到格心的球面直线距离约为 3.1–352.9m，中位数约 198.1m。该距离反映站点在固定网格中的位置，具有网格划分几何的成分，不能直接认定为网格级干预强度；不为它扩大第一版数据采集范围。

2026-10-12 发现的旧 AlphaEarth 提取脚本使用站点中心 ±0.0025° 窗口，未使用正式网格多边形。2026-10-13 已修正脚本并完成真实重提取，新缓存严格绑定参考网格 WKT 与几何哈希；旧 `data/active/alphaearth/` 仅作为历史对照。冻结网格及响应标签保持原有口径。独立卫星采集同样使用正式多边形，保留影像自身的来源、时间和像素有效掩码。

站点属性脚本依据现有线路归属、邻接关系与开通日期重建开通时属性，历史口径仍需按已有站点属性审阅流程核对。终点含缺失或换乘站歧义时保留缺失 mask，不把未知写成“非终点”。新增数值字段的预处理参数仅在训练集拟合。以上属性描述地铁事件，不需要采集街道路网。

`city_key`、`station_event_id`、站名和线路名称用于数据绑定与审计；第一版不将其原始类别编码直接加入干预预测特征。模型类型已有四个属性位时，无需另加基于站名的站点身份嵌入。

轨道网络的开通前后可达性增量可作为后续增强，但既有开通前可达性快照不能直接称为“干预增量”。使用该增强需另行构造有明确时点的开通前后轨道快照并核验历史口径。TOD 配套强度、班次或运力尚未确认有对应资产，第一版不默认输入这些字段。开通后的实际客流、房价、POI 或 VIIRS 变化不进入 `T_i`；这些变化属于结果或响应监督，不能用于开通前预测。

## AlphaEarth 的使用方式

AlphaEarth 的 64 维是共同表达地表信息的潜在坐标，没有独立的逐维物理语义。本轮完整向量进入背景 `ContextEncoder`，输出维数可为 16 或 32 等超参数。这里的低维投影不代表已经获得可解释的语义分解，也不按原始维度编号划分状态和背景。不使用 AlphaEarth 的路线作为背景消融对照保留。

本项目借鉴 AlphaEarth 用固定维度向量表达地点的表示思路；项目自己的状态 embedding `z_i` 由开通前 S 中的多模态输入共同学习，并由因果响应相似性监督优化。输入中的 AlphaEarth64 仍是背景字段之一，不等同于最终的项目 embedding，也不代表复刻 AlphaEarth 的基础模型训练方法。

官方来源：[Google Satellite Embedding V1 数据说明](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL)。该说明建议使用嵌入时使用全部维度。背景分支的归属是本次项目输入设计决定，具体收益仍需本项目的任务比较。

所有主预测输入保持既有信息截止规则。AlphaEarth 年度覆盖区间与开通日期核对，时间未知或不合法时屏蔽对应背景模态、保留事件。房价、人口和城市汇总量也按事件的信息截止日期构造。

独立卫星按每个事件开通年份加 `event_time=-6..+3` 逐年归档，包含开通当年，共 50,480 条记录。状态编码器仅使用开通前 `-6..-1` 的六年时序，共 30,288 条；开通当年与后三年影像供事后轨迹研究使用，不能作为主预测状态输入。未结束的日历年保留不可用记录；不能用部分年度或当前影像替代历史全年影像。

## 建议模型关系

```text
z_i = StateEncoder(poi_history_i, viirs_history_i, streetview_i, satellite_images_i, state_masks_i)
t_i = InterventionEncoder(T_i)
b_i = ContextEncoder(AlphaEarth_i[64], population_i, city_context_i, masks_i)
tau_hat_i = ResponsePredictor(concat(z_i, t_i, b_i))
```

对事件 `i`，唯一的响应表征 embedding 是多模态状态向量 `z_i=f_theta(x_i)`。`x_i` 由开通前 POI/VIIRS 历史、街景、独立卫星影像及对应 masks 共同组成。干预 `T_i` 与背景 `C_i` 编码为 `t_i`、`b_i`，作为响应预测器的条件，不并入 `z_i`。监督标签不进入编码器输入：因果响应预测损失训练 `g_phi(z_i,T_i,C_i)`，响应相似性损失则按响应轨迹相似度对齐 `z_i` 与 `z_j`。两项都使用有 mask 和可靠性权重的准实验因果响应 `tau_QE_i`。模型不预测开通后的街景或卫星影像。

街景的多张开通前图片是 `S_i` 中的可变长子输入，逐张使用距开通月的时间信息聚合，再与 POI/VIIRS 历史及独立卫星 `-6..-1` 年序列共同生成一个定长 `z_i`。当前项目分工把 AlphaEarth64、房价/人口和城市统计放在 `C_i`，所以这些字段进入响应预测条件而不是状态 embedding；这与街景和独立卫星影像使用不同来源和字段的约定一致。

既有 `CrossViewSynergyModule` 对应街景与 AlphaEarth 的融合方案，作为已有对照保留，不直接等同于新方案中的街景与独立卫星图像融合。AlphaEarth 缓存、时间元数据和掩码逻辑可以继续复用。

## 最小比较与验收

同一事件支持集、城市划分、信息截止日期和监督掩码下，比较：

| 实验 | 输入 | 目的 |
|---|---|---|
| 背景基线 | `T_i + C_i` | 衡量背景自身可以解释的预测能力 |
| 状态基线 | `z_i + T_i` | 衡量状态表示及干预信息的预测能力 |
| 完整模型 | `z_i + T_i + C_i` | 评价背景增量及状态在背景之上的增量 |

完整模型另比较移除 AlphaEarth 背景与移除卫星图像状态的版本，必要时对 POI、VIIRS 单独做消融，以衡量信息重叠及真实增量，不据来源不同预设完全互补。

背景向量的压缩维数只在训练/验证城市中确定。预处理不使用测试城市，主比较不以背景缺失为由改变测试事件集合。

用正式入口完成小规模“发布 → 训练 → 保存 → 导出 → 评估”，核对保存前后预测一致性，并报告是否使用真实街景。这里定义的是实现与验收目标，不宣称新架构已有性能收益。
