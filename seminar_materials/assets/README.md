# Seminar 图表素材

整理日期：2026-10-06。页码对应最终版 project_intro_seminar_final.pptx。

## 目录

- charts/data/：数据覆盖、样本支持与权重图。
- charts/causal/：event study 与处理前趋势图。
- charts/representation/：城市外对照、表示学习表现与增量图。
- diagrams/：现用方法示意图，以及完整 Pipeline。vector/ 保存可编辑的矢量流程图。
- equations/：公式的 PNG、SVG、PDF 与来源。
- illustrations/：背景插图。
- sources/：CSV 数据、结果口径、生成提示词与来源记录。

同名 PNG 用于直接插入 PPT；SVG 用于后续编辑；PDF 用于矢量排版。所有已有定量图表及公式均保留。未用于最终 PPT 的图表作为补充素材保留。
